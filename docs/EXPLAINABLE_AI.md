# Explainable AI (XAI) for 5G Wireless Intrusion Detection

## 1. Overview
The Explainable AI module (`explainable_ai/xai_engine.py`) provides evidence-based explanations for alerts generated by the HTSTCL-GNN model. It prevents "black box" decisions by exposing the underlying mathematical feature attributions and temporal window dynamics.

---

## 2. Gradient-based Spatio-Temporal Attribution
For a sequence $S = [G_1, G_2, \dots, G_5]$ with node features $x_{t,n,j}$ (where $t \in [1..5]$, node $n \in [1..5]$, feature $j \in [1..91]$):
1. **Backpropagation of Target Logit:**
   $$\nabla_{x_{t,n,j}} = \frac{\partial \hat{y}_c}{\partial x_{t,n,j}}$$
2. **Gradient $\times$ Input Energy:**
   $$\text{Attr}_{j} = \sum_{t=1}^5 \sum_{n=1}^5 \left| x_{t,n,j} \cdot \nabla_{x_{t,n,j}} \right|$$
3. **Temporal Window Attribution:**
   $$\text{WindowEnergy}_t = \sum_{n=1}^5 \sum_{j=1}^{91} \left| x_{t,n,j} \cdot \nabla_{x_{t,n,j}} \right|$$

---

## 3. Faithfulness Verification
To guarantee that the attributed features genuinely drove the model's decision:
- The top-1 ranked feature is perturbed (masked to zero).
- A second forward pass measures the drop in confidence:
  $$\Delta_{\text{score}} = P_{\text{original}}(c) - P_{\text{perturbed}}(c)$$
- If $\Delta_{\text{score}} \ge 0$, the explanation is verified as **Faithful**.

---

## 4. Human-Readable Synthesis
The engine translates mathematical gradients into analyst-friendly incident notes:
> "Verified UDPFlood attack detected on UE-10 via gNB-1 with 98.5% confidence. The decision was primarily driven by extreme packet transmission rates (Rate = 38.5%) and outbound flow volume (TotBytes = 26.2%), peaking in temporal window 5."
